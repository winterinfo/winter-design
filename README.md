## О проекте

**WINTER.DESIGN** — это персональный сайт-портфолио и витрина услуг веб-дизайна. Проект объединяет кейсы, SEO-страницы услуг и контактную форму в единую экосистему с премиальной типографикой, адаптивной вёрсткой и акцентом на пользовательский опыт.

Сайт разработан на чистом HTML, CSS и JavaScript без фреймворков — с фокусом на производительность, доступность и качество визуальной подачи.

---

## Возможности

- Адаптивный дизайн для desktop, tablet и mobile
- Семантическая HTML5-разметка и чистая CSS-архитектура
- Плавные анимации и scroll-reveal эффекты
- SEO-оптимизация: meta-теги, Open Graph, `sitemap.xml`, `robots.txt`
- Отдельные страницы кейсов и услуг
- Контактная форма с серверной отправкой
- Страница 404 и favicon-пакет
- Поддержка `prefers-reduced-motion` и focus-visible

## Локальный запуск

Проект — статический сайт, сборщик не требуется.

### Вариант 1 — Live Server (рекомендуется)

1. Клонируйте репозиторий:

```bash
git clone https://github.com/winterinfo/winter-design.git
cd winter-design
```

2. Откройте папку в VS Code / Cursor.
3. Запустите расширение **Live Server** на файле `index.html`.
4. Сайт откроется по адресу `http://127.0.0.1:5500`.

### Вариант 2 — Python

```bash
python -m http.server 8000
```

Откройте в браузере: `http://localhost:8000`

### Вариант 3 — Node.js

```bash
npx serve .
```
